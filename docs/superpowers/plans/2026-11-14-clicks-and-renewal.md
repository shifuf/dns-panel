# 点击性能与证书部署链路修复计划

这是早期阶段计划。用户后续已授权真实续期、平台绑定更新与宝塔目录部署；最终执行范围及结果见 [真实全平台续期验收](../../full-renewal-cycle-2026-11-14.md)。

**目标：** 修复七牛上传后检查错误、证书覆盖判断与误导提示，核实自动续期和宝塔同步，并改善已测量的首次导航延迟。

**约束：** 保留此前所有改动；不改用户现有平台绑定、HTTPS 设置或续期开关；服务器写入仅限 `/www/wwwroot/DNS`；插件安装目录只读。继续用户已选择的并行处理方式。

**已复现证据：** 七牛带 `%2A` 的域名路径报 401，保留 `*` 则准确返回域名不存在；通配证书被服务端字符串相等校验拒绝用于实际子域名；域名入口首次导航约 3 秒，直连源站约 60ms，重复导航约 35–50ms。

- [x] 七牛接口与平台服务：修复编码、单层通配匹配、上传前目标预检、上传/绑定状态区分；以实际请求形状和路由行为回归测试覆盖。
- [x] 部署弹窗：不自动填入泛域名，校验证书覆盖，区分部分失败，阻止旧异步凭证响应回填。
- [x] 导航：确认缓存和竞态，添加意图预加载及即时加载反馈，以真实浏览器复测冷/热导航。
- [x] 静态资源：nginx 对带 hash 的 assets 设置长期缓存，HTML 重新验证，API 禁止缓存；挂载已有目录内的配置文件并验证。
- [x] 续期与宝塔：核对后台 worker、失败重试、部署事件领取和插件定时任务；修复确认的断链问题并出更新包。
- [x] 验证：后端/插件测试、前端测试和生产构建；复查权限、单层泛域名、跨会话竞态、部分成功和失败重试。
- [x] 部署与验收：仅更新授权目录，保留配置/数据库/有效证书；只读核验七牛和续期开关，刷新面板 HTML 缓存，记录性能前后对比与插件安装限制。

功能建议依据本轮故障整理，不默认添加未经明确要求的新业务模块。
