## Cloudflare 的 5 个域名为什么只显示 1 个

使用本地数据库中保存的 Cloudflare 凭证，只读调用官方 `/zones` 接口。分别请求 `per_page=50` 和 `per_page=100`，均返回 **1 个域名、total_count=1、total_pages=1**。这说明当前保存的 Token 在上游只能看到一个域名，不能归因于前端把五条数据隐藏成了一条。

需要在 Cloudflare 核对该 Token 的 Zone Resources 是否覆盖全部五个域名，以及 Token 所属用户/账户的访问权限。本次没有修改 Token、账户权限或实际 DNS。更新凭证后，在面板验证凭证并刷新域名；新页面会显示当前范围与可见数量，刷新失败会保留具体错误。

与此同时，代码中存在与数量显示有关的独立缺陷，已修复：

- 上游每页返回少于请求数量时，继续根据总数翻页。
- 重复页、缺失页和分页上限会明确报错，避免把不完整结果展示为完整结果。
- 子查询遵循缓存过期和失效状态。
- 凭证新增、更新、验证、删除、备份恢复和手动刷新会同步处理缓存。
- 显示加载失败和重试入口，避免刷新失败仍提示成功。

## Cloudflare Tunnel

- 独立选择 Cloudflare 凭证和账户，支持从其他服务商页面进入。
- 分页读取账户、Tunnel、私网路由，排除已删除的 Tunnel；不完整结果明确报错。
- 新建 Tunnel 使用 Cloudflare 远程管理配置。
- 公共路由自动匹配所属域名，也可手动选择；支持路径展示和服务地址编辑。
- 校验主机名、服务地址、CIDR；保留额外 ingress 配置和兜底规则。
- 拒绝覆盖指向其他目标的 CNAME。
- 删除单一路径时，保留同一主机名其他路径仍使用的 DNS。
- 删除 Tunnel 前读取匹配 DNS；扫描失败不删除 Tunnel，Tunnel 删除失败不删 DNS，部分 DNS 清理失败返回明细。
- 补齐移动端详情、连接状态、本地托管提示和错误提示。
- 安装 Token 按需展示，仅保存在组件内；服务端响应禁止缓存。
- 凭证变更和恢复备份会清除 Tunnel 相关缓存，避免继续使用旧 Account ID。

使用本地保存的凭证只读查询真实 Tunnel 列表，接口正常，当前所选账户返回 0 条。

主机名或路径需要改变时，使用新建路由后删除旧路由；当前编辑入口针对服务地址。自动清理只能覆盖所选账户下当前 Token 可见的域名。

## 七牛云 401 bad token

已确认鉴权根因，并通过同一组用户凭证验证：

| 验证 | 结果 |
| --- | --- |
| 读取证书列表 | HTTP 200 |
| 原签名提交空证书 JSON | HTTP 401，bad token |
| 修正签名提交同一空 JSON | HTTP 400，证书解码错误，说明已通过鉴权 |
| 修正后的 CDN 域名列表 | 成功 |
| 修正后的 CDN 域名详情 | 成功 |

空请求不包含证书或私钥，未创建证书、绑定域名或改变云端配置。真实证书上传与部署需在更新运行中的面板后执行。

修复覆盖：

- `fusion.qiniuapi.com` 证书接口使用 QBox，JSON 正文不参与签名。
- `api.qiniu.com` 域名接口使用 Qiniu v2，签入方法、Host、时间和实际请求正文。
- 修正域名详情接口、marker 分页和 `certId` 字段。
- 首次开启 HTTPS 与替换已有证书使用不同接口。
- 自动换证保留原有强制 HTTPS 设置；显式关闭仍受支持。
- 不再把 403 鉴权错误伪装成“未绑定”；HTTP/3 状态不再混入强制 HTTPS。
- 错误响应正文只读取一次，保留服务商错误信息。

凭证没有写入代码、测试、报告或仓库文件。
