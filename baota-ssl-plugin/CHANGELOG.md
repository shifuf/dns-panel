# 2.1.1 — 2026-11-14

- 自动同步保留续期接口错误和逐证书失败原因，不再将这些失败报告为成功。
- 一个或多个宝塔站点部署失败，或部署结果回传失败时，同步结果明确标记失败。
- 续期请求失败后，仍尝试部署面板中已经签发的有效证书。
- 包含 2.1.0 的站点及反代来源上报能力。安装保留现有 `config.json`、站点白名单和续期开关。

面板后台同时修复了腾讯续期函数调用顺序，以及通配符证书续期后匹配已保存 CDN 子域绑定的问题。后台更新与插件安装是两项独立操作；仅更新后台不会替换已安装插件。

本更新包不会修改云平台绑定。证书续期和同步是否执行，继续取决于现有开关、续期窗口、DNS 凭证、平台绑定和宝塔计划任务。
